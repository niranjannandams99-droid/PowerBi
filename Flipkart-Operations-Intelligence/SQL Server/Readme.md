# SQL Server – Data Preparation & Business Analytics

## Overview

This layer provides the relational database foundation for the Flipkart Operations Intelligence project.

The objective is to prepare structured and reliable operational data for downstream analytical modelling and business reporting.

## Key Activities

- Organised the operational dataset for relational database processing.
- Used SQL queries for data preparation, transformation and validation.
- Developed SQL scripts to support analytical requirements.
- Structured dimension-related data to support analytical modelling.
- Prepared the database layer for integration with SSIS and SSAS.

## Technology Stack

- Microsoft SQL Server
- T-SQL
- SQL Server Management Studio (SSMS)

## Role in the Architecture

SQL Server acts as the central relational data layer between ETL processing and analytical modelling.
