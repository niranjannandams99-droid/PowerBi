# Power BI Dashboard Screenshots

## Overview

This folder contains the visual previews of the **Flipkart Operations Intelligence & SLA Performance Analytics** dashboard, developed using Microsoft Power BI.

The dashboard is organised into six analytical pages, each focusing on a specific business and operational perspective.

## Dashboard Pages

| No. | Dashboard Page | Description |
|---|---|---|
| 1 | Executive Overview | High-level business performance, sales and operational KPIs |
| 2 | Sales & Orders Analysis | Revenue trends, order distribution and category performance |
| 3 | Delivery & SLA Analysis | Delivery performance, SLA compliance and breach analysis |
| 4 | Cancellation Analysis | Cancelled orders and cancellation patterns |
| 5 | Customer Insights | Customer segments and purchasing behaviour |
| 6 | Management View | Consolidated KPIs for management-level monitoring |
