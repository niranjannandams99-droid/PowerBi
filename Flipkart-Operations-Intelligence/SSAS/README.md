# SSAS – Tabular Analytical Model

## Overview

The SSAS layer provides the analytical modelling foundation for the Flipkart Operations Intelligence solution.

The objective is to organise business data into a semantic model that supports consistent measures, relationships and analytical reporting.

## Key Activities

- Developed an SSAS Tabular project.
- Created the analytical model using the Tabular model definition.
- Organised the model for business-oriented analysis.
- Prepared the semantic layer to support Power BI reporting.
- Connected the analytical modelling layer with the wider SQL Server data architecture.

## Technology Stack

- SQL Server Analysis Services (SSAS)
- Tabular Model
- Visual Studio
- DAX

## Project Files

| File | Purpose |
|---|---|
| `Model.bim` | Tabular model definition |
| `Model.bim.layout` | Model layout metadata |
| `SSAS_Flipkart_Model.slnx` | Visual Studio solution |
| `SSAS_Flipkart_Model.smproj` | SSAS project definition |

## Role in the Architecture

SSAS acts as the semantic modelling layer, providing a structured analytical foundation for business intelligence reporting.
