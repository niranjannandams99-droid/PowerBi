# F1 World Championship Performance Intelligence Dashboard

## Project Overview

This project analyzes Formula 1 World Championship data from 1950–2024 using Power BI.

The dashboard integrates 14 relational tables covering:

- 75 Seasons
- 1,125+ Grand Prix
- 860+ Drivers
- 210 Constructors
- 77 Circuits

## Business Problem

Formula 1 generates massive amounts of race and performance data.
The objective was to transform historical race data into an interactive
Performance Intelligence Dashboard for driver, constructor, and circuit analysis.

## Tools Used

- Power BI
- Power Query
- DAX
- Data Modeling
- Kaggle Dataset

## Dashboard Pages

1. Home
2. Season Command Center
3. Driver Analytics
4. Constructor Dominance
5. Circuit Intelligence

## Key Insights

- Lewis Hamilton: 105 wins
- Ferrari: 249 wins
- Mercedes dominated the 2010s
- Red Bull dominance emerging in the 2020s
